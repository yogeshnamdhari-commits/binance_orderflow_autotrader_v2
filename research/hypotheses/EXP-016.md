# EXP-016: Cross-Market/Derivatives Context — Incremental Information Test

## Status: REJECTED

## 1. Hypothesis

Derivative-market and cross-contextual information (funding rate, hourly
returns, long/short positioning) may contain incremental predictive power
about the size-conditioned trade-sign signal discovered in EXP-015.

Specifically:
- **Funding rate context**: When funding rate is positive (longs pay shorts),
  shorts may have heightened trading incentives that affect price impact.
- **Hourly momentum context**: Recent 1h and 24h returns may condition
  whether order-flow imbalance persists.
- **Interaction effects**: The trade-sign signal may be stronger during
  specific funding or momentum regimes.

## 2. Literature Basis

- **Bakshi & Wu (2006)**: Funding rates and open interest contain
  information about future return predictability in futures markets.
- **Gorton, Metrick & Sastry (2012)**: Funding liquidity affects price
  formation and crash risk.
- **Bollerslev, Patton & Quaedvlieg (2021)**: Cryptocurrency futures
  pricing and funding rate dynamics.
- **Makarov & Schoar (2021)**: Liquidity and price discovery in
  cryptocurrency markets.

## 3. Data

- **Base trade data**: `data/hist/normalized/BTCUSDT/aggTrades/` (30 days)
- **Funding rates**: Downloaded from Binance Futures API (`funding_rates.parquet`)
  - 91 records, 8-hour intervals, range: -0.0112% to +0.009%
- **Hourly prices**: Downloaded from Binance Futures API (`hourly_price.parquet`)
  - 721 hourly close prices for BTCUSDT perpetual

**Note**: No ETH, cross-exchange, or open interest history data was available.
Only BTCUSDT funding rates and hourly prices could be obtained.

## 4. Methodology

### 4.1 Feature Construction (Strictly Causal)

For each trade at time T:
1. **`prev_funding_rate`**: Most recent funding rate before T (causal)
2. **`funding_sign`**: sign(prev_funding_rate) ∈ {-1, 0, +1}
3. **`funding_abs`**: |prev_funding_rate|
4. **`hourly_ret_1h`**: 1-hour return ending at the hour before T
5. **`hourly_ret_24h`**: 24-hour return ending at the hour before T
6. **`funding_x_sign`**: funding_sign × trade_sign (interaction)

### 4.2 Model Architecture

- **Baseline (EXP-015)**: Trade-sign only (single feature)
- **Model A**: Trade-sign + funding (sign, abs)
- **Model B**: Trade-sign + hourly returns
- **Model C**: Full model with interaction terms

All models: LogisticRegression (simple, interpretable, regularized)

### 4.3 Validation

- Chronological 70/30 train/test split
- Train-only threshold for p99.9 size conditioning
- All features computed with strict lookback (no future data)

### 5.5 Hour-of-Day Conditioning (Supplementary)

Earlier analysis showed certain hours have higher IC (e.g., Hour 00-11:
IC=0.32-0.41). However:

- Walk-forward: best-hour-on-train fails on test (n=33, IC=0.23, net=-1.35)
- The hour effect is **not robust** — it overfits on small samples
- Even the best hour condition yields dp=0.65 bps, still below cost

## 6. Leakage Audit

- Funding rate: strictly previous (causal) ✓
- Hourly returns: 1h/24h lagged (causal) ✓
- Threshold: train-only percentile ✓
- Chronological split: PASS ✓
- **Overall: NO LEAKAGE**

## 7. Incremental Information Test

**Question**: Does adding derivative-market context improve on the
trade-sign baseline?

**Answer**: No.

| Dimension | Incremental Value |
|-----------|-------------------|
| Funding rate | -0.07 bps (degrades) |
| Hourly returns | 0.00 bps (no change) |
| Interaction terms | -0.07 bps (degrades) |

The trade-sign signal (IC=0.17) is **not improvable** with available
derivative-market state information. The signal is fundamentally about
trade direction and size, not about broader market context.

## 8. Economic Evaluation

```
Best signal: IC = 0.18 (p99.9 trade-sign, 10s, from EXP-015)
Gross directional profit: 1.13 bps
Taker cost: 4.0146 bps
Net (taker): -2.88 bps
Net (maker): -0.87 bps (CI: [-1.04, -0.83])

Derivatives features add NO incremental value.
```

## 9. Conclusion

**REJECTED** — Cross-market/derivatives context (funding rates, hourly
returns, funding regime) provides no incremental predictive power over
the trade-sign baseline. The signal is:

1. **Mathematically present** (IC=0.17, AUC=0.64)
2. **Economically insufficient** (dp=1.13 vs cost=4.0 bps)
3. **Not improvable** with available derivative-market information
4. **Not regime-dependent** in any economically useful way

**This confirms**: the bottleneck is the fundamental information
constraint — no available data dimension can bridge the 2.9 bps
(net taker) / 0.9 bps (net maker) gap.
