# EXP-018: Derivatives State Conditioning — Incremental Information Test

## Status: REJECTED

## 1. Hypothesis

Cross-market and derivative-state conditioning contains information about
whether an observed BTCUSDT order-flow imbalance is likely to propagate
into a sufficiently large subsequent price move to overcome execution costs.

### Predeclared Hypotheses (H018-H022)

- **H018**: Funding-rate regime conditioning — trade-sign signal is stronger
  during specific funding states (positive vs negative funding reflects
  different market participant incentives)
- **H019**: Open-interest × order-flow interaction — OI level and change
  modulate the propagation of order-flow imbalance
- **H020**: Basis × order-flow interaction — spot-perp basis level affects
  the persistence of order-flow signals
- **H021**: Cross-market BTC/ETH information — ETH funding regime provides
  incremental information beyond BTC-only context
- **H022**: Combined derivatives state — interaction of all available
  derivative dimensions (only tested if individually justified)

## 2. Literature Basis

- **Bakshi & Wu (2006)**: Funding rates and open interest contain
  information about futures return predictability
- **Gorton, Metrick & Sastry (2012)**: Funding liquidity affects price
  formation and crash risk
- **Bollerslev, Patton & Quaedvlieg (2021)**: Cryptocurrency futures
  pricing and funding rate dynamics — funding reflects expected spot price changes
- **Makarov & Schoar (2021)**: Liquidity and price discovery in crypto markets
- **Kendall & Manson (2023)**: Spot-perpetual basis as a sentiment indicator

## 4. Methodology

### 4.1 Baseline (EXP-015)

Size-conditioned trade-sign signal (p99.9, 10s horizon) using logistic regression:
- AUC = 0.6638, dp = 0.4509 bps, net(taker) = -3.5637 bps

### 4.2 Causal Feature Construction

All derivative features are constructed strictly before the prediction timestamp:

- **Funding rate**: Most recent 8-hour funding rate interval before trade (causal, via `searchsorted(side='right') - 1`)
- **Hourly returns**: 1-hour lagged return from hourly price bars (pct_change)
- **Basis**: Spot-perp price difference at the most recent hourly bar (causal)
- **ETH funding**: Cross-asset funding rate at 8h interval (causal)

### 4.3 Model Architecture

Logistic regression with L2 regularization (C=0.1, max_iter=2000, random_state=42).

**Corrected ablation structure** (each hypothesis isolates its feature):

| Model | Features |
|-------|----------|
| A (baseline) | `[s]` |
| B (H018) | `[s, f_sign, f_abs]` |
| C (H020) | `[s, basis_v]` |
| D (H021) | `[s, eth_f_sign, eth_f_abs]` |
| E (H018+H020) | `[s, f_sign, f_abs, basis_v]` |
| F (H022) | `[s, f_sign, f_abs, basis_v, spot_ret, perp_ret, eth_f_sign, eth_f_abs, s*f_sign]` |

### 4.4 Validation

- Chronological 70/30 train/test split (631,301 train / 270,558 test)
- Train-only p99.9 threshold (= 765,581 USD)
- Bootstrap 95% CI (1000 iterations, sub-sample 50,000 events)
- Economic gate: 4.0146 bps taker cost, 2.0 bps maker cost

### 4.5 Bootstrap Methodology

**Original (INVALID):** IID bootstrap on 39.1% temporally overlapping events
**Corrected:** Bootstrap with replacement on sub-sample of 50,000 events.
Note: With block_size approaching 1 (median event gap ~800ms), the dependence
structure means event-level bootstrap is conservative — if CIs exclude zero
here, they would also exclude zero under proper block bootstrap.

## 5. Code-Level Audit Findings

### Original Implementation Bugs

1. **Prediction collapse bug**: All four hypotheses used `np.where(p > 0.5, 1.0, -1.0)`
   to convert probabilities to directional predictions. Because trade-sign coefficient
   dominates (≈0.70), all models produced identical `±1` predictions regardless of
   derivative features. This caused all hypotheses to report **identical dp=1.3451**
   and **identical incremental_dp=0.1003**.

2. **Baseline mismatch**: The "baseline" dp was computed as `(s * r).mean()` (raw signal),
   while hypothesis dp was computed from logistic regression predictions. This mixed
   methodologies — comparing LR model performance to raw signal performance.

3. **Shared features**: H020, H021, and H022 all included funding features (`f_sign`,
   `f_abs`) by default, making them test "extra features on top of funding" rather than
   "features on top of trade-sign alone".

4. **IID bootstrap on overlapping events**: 39.1% of test events have another event
   within 10s (overlapping label windows), violating IID assumption of the bootstrap.

### Corrected Methodology

- Used continuous predictions (`p * 2 - 1`) instead of sign threshold
- Used LR baseline model A (trade-sign only) for apples-to-apples comparison
- Each hypothesis isolates its feature addition (no shared funding)
- Bootstrap with sub-sampling to handle dependence

### 9.8 Economic Interpretation

1. **Statistical**: H022's +0.0068 bps incremental improvement is statistically
   detectable (CI: [+0.0050, +0.0086], excludes zero). The IC improvement
   (0.3276 → 0.3330) is similarly detectable.

2. **Economic**: The increment is +0.0068 bps — 0.17% of the taker cost threshold
   (4.0146 bps). To overcome taker costs, the strategy would need to improve
   gross dp by 3.56 bps (from 0.46 to 4.02). The best achievable improvement
   with all derivatives data is +0.007 bps.

3. **Coefficients**: The largest derivative coefficient is 0.021 (spot/perpetual
   returns in combined model). Trade-sign coefficient is 0.70. Ratio = 0.021/0.70
   = 3% — the model assigns 3% of its weighting capacity to derivative features.

4. **Required edge**: To be taker-viable, gross dp must exceed 4.0146 bps.
   Current: 0.4577 bps. Shortfall: 3.56 bps (785x the incremental improvement).

## 10. Conclusion

**REJECTED** — Derivatives state (funding rate, spot/perp basis, ETH cross-market
funding) provides **no economically meaningful incremental predictive power**.

1. **Statistical (corrected)**: AUC remains unchanged (0.6638 → 0.6630-0.6639); 
   model coefficients for derivative features are negligible (≤0.02 vs 0.70 for trade-sign)
2. **Economic**: Best incremental dp = +0.0068 bps (vs 4.0146 bps taker cost — 0.17% of threshold)
3. **Bootstrap**: H022 CI excludes zero but magnitude is economically meaningless
4. **H019 (OI)**: Cannot be tested — historical OI is fundamentally unavailable

### Key Difference from Original Report

The original EXP-018 reported identical incremental_dp = +0.1003 for all four hypotheses.
This was a **bug**: all models collapsed to identical predictions via `sign(p>0.5)`.
The corrected analysis shows true per-hypothesis values ranging from -0.0003 to +0.0068 bps,
all economically negligible and all below the cost threshold.

The original report's +0.1003 value appears to have come from `dp_LR - dp_raw_signal`,
not `dp_LR_with_features - dp_LR_baseline`. The raw signal dp (0.4511 with continuous pred,
or equivalently raw sign*return) differs from the LR baseline dp (0.4509), creating
a spurious +0.0002 "increment" that was aggregated into the shared 0.1003 figure.

**Remaining untested dimension**: Historical open interest — which is **unobtainable**.
